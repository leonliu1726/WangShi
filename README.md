# 往事 · 老建回忆录

范建华（老建）回忆录《往事》的网站。2022 年 2 月多伦多第一版，ISBN 978-1-7779335-1-7。

- **正文**：取自 `往事书稿定稿.pdf`（与 Word 稿逐字核对一致），一字未改，只按原书分段。
- **插图**：42 幅黑白版画，每幅挂在所画情节的那一段之后；图下说明只摘该段原文。
- **照片**：书内 6 张老照片，位置与原书一致。
- **页面**：封面、序、自序、正文十三章、生活纪事九篇、后记、画卷、版权页，共 28 页。
- **阅读**：目录抽屉、字号、夜读、阅读进度；记住上次读到的章节；← → 键翻页。手机、电脑都适配。
- 页面带 `noindex`，搜索引擎不收录，等作者决定是否公开再去掉。

配图审阅意见见 [docs/配图审阅.md](docs/配图审阅.md)，交给出图工具的完整指令见 [docs/出图指令.md](docs/出图指令.md)。

## 重新生成

```
cd tools
python3 build.py book.json <配图目录> <书内照片目录> ..
```

需要 Python 3 和 Pillow。插图的位置和说明在 `tools/plates.py`，每幅一行；生成时会检查定位句和说明是否逐字出自原文，对不上就报错停止。
